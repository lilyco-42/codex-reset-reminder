## 打之后 CI 会做什么（已实测的行为）

- tag 匹配 `v*` → `ci.yml` 全矩阵跑（含 `ios`，push 时它是 skip 的）。
- `release` 作业的条件是 `always()` 且只要求 `desktop` 与 `android` 成功 → **ios 红了也会出 Release**，
  少一个 ipa 而已。这不是妥协：ipa 本来就是加分项（未签名，需 SideStore/AltStore 重签）。
- `ios` 这一步现在用 `scripts/with-retry.sh`（最多 3 次尝试、间隔 20 s），因为它构建时要临时从 GitHub 取
  SwiftPM 依赖 `Brendonovich/swift-rs`，runner 上出现过抓取失败导致 `xcodebuild 65`（run 38279394332 实测；
  下一次 run 38280640899 第一次就过了，所以重试分支本身当时没被触发 —— 逻辑改由 `test-with-retry.sh` 覆盖，
  并做过变异测试：去掉重试或把用法错误改成 exit 0，那个自测都会红）。
